# MountVega

MountVega is a Big-data Geo-processing Engine that enables scalable, aggregation and analysis with auto-scaling capabilities and distributed architecture.

MountVega is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- MountVega is a Big-data Geo-processing
- Engine that enables scalable, aggregation
- and analysis with auto-scaling capabilities

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/MountVega.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure MountVega, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
